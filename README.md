# DentAssist AI

Real-time AI assistant that helps dentists document treatments while they work.

The system listens to speech during treatment and automatically converts it into structured medical records.

## Features (MVP)

- Speech → Text transcription
- Medical information extraction
- Automatic patient record generation
- Appointment scheduling

## Project Architecture

Audio → Speech Recognition → Medical NLP → Patient Record → Scheduler

## Technologies

- Python
- Whisper (Speech Recognition)
- FastAPI
- OpenAI / LLM
- OpenCV
- YOLOv8
